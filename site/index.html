ludin은 Node.js용 API 문서 미들웨어입니다. 기존 OpenAPI 문서 도구가 예쁘게 보여주는 데서 멈춘다면, ludin은 그 위에 로그인, 역할, IP 화이트리스트, 감사 로그를 한 줄로 얹습니다.

GitHub에서 보기 npm
$npm i @ludin-docs/core @ludin-docs/express
한 줄로 시작

이미 있는 앱에 마운트하면 끝

OpenAPI 파일 경로나 객체를 넘기고, 계정과 IP 규칙을 코드나 환경변수로 적습니다. 붙일 인프라가 없어서 5분이면 올라갑니다.

import { ludin } from '@ludin-docs/express';

app.use('/docs', ludin({
  spec: './openapi.yaml',
  auth: { users: [{ email: 'me@corp.io', password: process.env.DOCS_PW, role: 'admin' }] },
  ipAllowlist: ['10.0.0.0/8', '203.0.113.0/24'],
  visibility: { 'tag:Admin': ['admin'] },   // admin이 아니면 이 태그는 존재하지 않는다
  share: { enabled: true },                // 만료되는 공유 링크
  mcp:   { enabled: true },                // AI 에이전트용 엔드포인트
}));
접근 통제

문서를 여는 모든 경로가 한 파이프라인을 지납니다

IP 검사 → 세션 → 역할 → 스펙 필터링 → 렌더 → 감사 기록. 문서 UI도, 스펙 JSON도, Try it out 프록시도, 에이전트 엔드포인트도 예외 없이 같은 순서로 검사됩니다.

로그인
이메일/비밀번호. scrypt 내장, bcrypt·argon2 선택. 서명된 HttpOnly 쿠키 세션, 실패 횟수 기반 잠금. 사내 인증에는 verify(email, password) 콜백으로 연결.
역할
viewer · developer · admin 기본 3단계에 커스텀 역할 추가. 권한은 docs:read, docs:try, admin:read 셋.
IP 화이트리스트
CIDR, 단일 IP, 범위, IPv6. 리버스 프록시 뒤에서는 trustProxy로 신뢰할 hop 수를 지정. IP만으로 통과시키는 ipPolicy: 'or'도 가능.
가시성
태그·경로·메서드 단위로 visibility를 걸면 그 역할은 해당 오퍼레이션이 존재하지 않는 문서를 받습니다. 검색 인덱스, 코드 샘플, 내보내기 전부 필터링 후의 문서에서 생성됩니다.
감사 로그
로그인 성공·실패, 열람, 내려받기, API 호출(메서드·경로·상태·소요시간), IP 차단. 기본은 JSON lines로 stdout, 원하는 싱크로 교체 가능. 민감 헤더는 마스킹.
Try it out
브라우저가 아니라 서버 프록시가 호출합니다. 그래서 모든 호출이 사용자에게 귀속되고, 스펙의 servers 밖으로는 나가지 않습니다. 같은 origin의 세션 쿠키 API도 옵션으로 시험 가능.
문서 품질

읽는 문서에서, 믿을 수 있는 문서로

무거운 계산은 전부 서버에서 합니다. UI는 결과만 그리므로 가볍고, 어느 것도 역할 필터를 우회하지 않습니다.

코드 샘플
curl · fetch · axios · Python · Go · .http. 서버 URL, 인증 헤더, 바디 예시가 채워진 채로 나옵니다.
⌘K 검색
경로·요약·operationId·태그에 더해 스키마 필드명까지. "createdAt을 돌려주는 API가 뭐지"에 답합니다.
응답 검증
Try it out 응답을 문서화된 스키마와 대조해 어긋난 곳을 표시합니다. 봉투 응답({ data: … })도 인식.
건강 점수 · lint
설명 누락, 예시 없음, 응답 스키마 없음 같은 항목을 점수로. ludin lint spec.yaml --min 80으로 CI에서 강제.
스펙 diff
이전 버전과 비교해 breaking change를 분류합니다. 경로 삭제, required 추가, enum 축소, 타입 변경, 응답 코드 제거. --markdown으로 릴리스 노트까지.
3.1 웹훅
API가 나를 호출하는 방향의 오퍼레이션도 렌더합니다. 가시성 규칙은 웹훅에도 똑같이 적용.
밖으로 내보내기

파트너에게도, 에이전트에게도, 딱 그만큼만

나가는 모든 것은 받는 사람의 역할로 필터링된 문서에서 만들어집니다. 읽을 수 있는 만큼만 가져갈 수 있습니다.

공유 링크
역할, 유효 기간, 스펙, 실행 허용 여부를 정해 발급. 첫 사용 시 URL에서 HttpOnly 쿠키로 옮겨가 리퍼러·기록에 남지 않습니다. 관리자 권한은 절대 담을 수 없습니다.
Postman · TypeScript
Postman v2.1 컬렉션과 .d.ts 선언 파일. 자격 증명은 변수로만, 타입은 보이는 오퍼레이션에서 도달 가능한 스키마만.
MCP 엔드포인트
AI 에이전트가 목록·검색·상세·실행 네 가지 도구로 문서를 씁니다. 새 API 키 없이 공유 링크나 세션으로 인증하고, 실행은 docs:try가 있어야만 보입니다.
# 읽기 전용 공유 링크를 에이전트에 물려주면
# 검색·조회는 되고 call_operation은 목록에 없다
POST /docs/api/mcp
Authorization: Bearer <share-token>

{ "method": "tools/list" }

→ list_operations
  search_operations
  get_operation
  (call_operation: docs:try 필요)
설계 원칙

DB가 없습니다

계정, IP 규칙, 역할 전부 코드와 환경변수에서 옵니다. 관리 화면은 현재 설정을 읽기 전용으로 보여줄 뿐입니다. 붙일 인프라가 없으니 5분이면 올라가고, 뚫릴 저장소도 없습니다. 런타임 의존성은 사실상 0입니다.

LUDIN_USERS=me@corp.io:$scrypt$…:admin,
            partner@x.io:$scrypt$…:viewer
LUDIN_IPS=10.0.0.0/8,203.0.113.0/24
LUDIN_SESSION_SECRET=…
